# Coolcook

App de recettes et de planification de repas.

PWA en HTML/CSS/JS vanilla (pas de framework, pas de build step), sur le même modèle que
[Cantrip](https://github.com/benwatz/cantrip).

## Déploiement

- **Prod** (GitHub Pages) : déploiement automatique à chaque push sur `master`, qui sert
  directement `index.html` à la racine.
